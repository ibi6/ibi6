## 在做什么

- 开源小工具与可复制的前端组件
- 本地优先的桌面 / CLI 仪器
- 安全基本功教学与授权范围内的低影响检查台
- 把复杂流程收成安静、可审阅的界面

## 作品精选

| 项目 | 说明 |
| --- | --- |
| [ui-components-oss](https://github.com/ibi6/ui-components-oss) · [Demo](https://ibi6.github.io/ui-components-oss/) | 零依赖纯前端 UI 组件集：抽屉、选择器、分页、双滑块、Toast… |
| [how-it-works-cn](https://github.com/ibi6/how-it-works-cn) · [Demo](https://ibi6.github.io/how-it-works-cn/) | 全中文可交互原理课：互联网 / Web 安全基本功（含 SRC 入门专题） |

| [signal-garden](https://github.com/ibi6/signal-garden) | 纯 HTML/JS 的生成式信号花园：会呼吸的可视化小品 |
